# VRK Traders – real-image website source

## Replace these files in your existing Vite React project
- `src/App.jsx`
- `src/products.js`
- `src/index.css`
- `src/main.jsx`

## Install icon dependency if needed
```bash
npm install lucide-react
npm run dev
```

The page uses external Pexels image URLs for real coconut/plantation imagery. For production, download images you have permission to use into `public/images/` and change the image URLs to local paths such as `/images/coconut-plantation.jpg`.

Important: In `src/App.jsx`, change `BUSINESS_EMAIL` from `your-email@example.com` to the real VRK Traders business email before publishing.

The supplied photos are references and may not precisely depict the specific husked/semi-husked grade you sell; verify images before publication.
